Event booking platform

Dinner Dance (events platform)

General-purpose social event booking tool

Not just the dinner dance — this is the reusable platform for club social events. Staff create and publish an event (optionally drafted by AI from a short description), and each event gets its own shareable booking link. Organisers book a table, add guests and menu choices, and can amend later via a private link — no accounts needed. Payment is handled outside the app, via Adfin, from staff's exported data.

Open platform ↗
  • /e/<event-slug>— an organiser's booking page for one published event
  • /adminStaff login— staff dashboard: list events, publish, export bookings
  • New/edit eventStaff login— reached from the dashboard; draft an event by hand or via AI assist
  • Staff sign in— password login for admins/editors
  • Create your account— one-time bootstrap for the first staff account; disables itself after use
Pages marked Needs club key / login are staff-only — you'll need the club access key, admin key, or staff login for that site (from whoever set it up, or the Netlify environment variables for that project). They aren't linked with the key included, so this page is safe to share more widely among staff.
